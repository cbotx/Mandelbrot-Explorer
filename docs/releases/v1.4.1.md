# Mandelbrot Explorer v1.4.1

This maintenance and performance release accelerates non-analytic and mixed generic formula perturbation, fixes rendering responsiveness during fast mouse wheel navigation, and enhances Formula Editor live preview feedback.

## Highlights

- **Non-Analytic & Mixed Formula Acceleration**:
  - Expanded generic perturbation classification to unblock complex modulus `abs(z)` and mixed formulas (`sin(real(z))`, `log(z)+conj(z)`, `tan(norm(z))`).
  - Enabled 4-lane AVX2 centered residual evaluation identity for complex modulus, avoiding expensive per-pixel MPFR fallbacks and achieving up to 24x speedups over MPFR with 100% bit-exact parity.

- **Responsive Navigation & Fluid UI Interaction**:
  - Fixed multi-notch wheel event accumulation (`WM_MOUSEWHEEL`), ensuring fast mouse wheel flicks accurately register all scroll steps.
  - Added non-blocking OpenMP cancellation checks across perturbation loops, allowing background renders to halt in <1ms without freezing or stuttering the main Win32 UI thread.

- **Formula Editor Live Preview & Viewport Reset**:
  - Added instant viewport reset and live preview rendering when editing formula text, switching presets, or adjusting complex variables (A, B, C, D, Z0) and bailout values in the Formula Editor.

- **Moderate-Zoom Interior Performance Calibration**:
  - Calibrated interior detection thresholds (`MANDEL_INT_EPS`), achieving up to 5x faster rendering on high-iteration interior-dense views.

## Export and Portability

The Windows x64 package contains the precompiled executable (`mandel_gui.exe`) and all required runtime dependencies and third-party notices.
