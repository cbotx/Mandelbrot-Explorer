# Mandelbrot Explorer v1.4.0

This release expands Mandelbrot Explorer from a quadratic deep-zoom viewer into
a native formula workbench while preserving exact deep-rendering fallbacks.

## Highlights

- Arbitrary complex expressions with a docked formula editor, c/z0 plane
  bindings, fixed constants, parameters, presets, and orbit inspection.
- Julia rendering and high-resolution export for Mandelbrot, Julia, and custom
  expressions.
- Certified generic deep zoom with Taylor tiles and exact MPFR fallback across
  arithmetic, entire, meromorphic, branch-sensitive, and piecewise formulas.
- AVX2 expression execution, invariant hoisting, exact hybrid lane refill,
  W^X JIT compilation, vectorized complex trigonometric opcodes, and exact
  periodic interior detection.
- Smooth, distance, feather, relief, analytic normal, orbit-trap, and
  DE-overlay coloring where supported.
- Optional D3D11 shallow Mandelbrot backend with exact CPU fallback.
- Corrected FloatExp BLA residual handling at extreme zoom.

## Export and portability

The Windows x64 package contains the executable and all non-system runtime DLLs.
PNG export uses Windows Imaging Component and supports supersampling, bounded
strip memory, progress, cancellation, resized-view aspect matching, and generic
deep formulas.

## Notes

- An AVX2-capable x64 processor and Windows 10 version 1607 or later are
  required.
- The D3D11 GPU backend and experimental generic centered4 backend remain
  opt-in; CPU rendering is the default.
- Some arbitrary formulas at extreme zoom necessarily fall back to per-pixel
  MPFR and can be slow.
- The executable is not code-signed; verify the published SHA-256 checksum if
  Windows SmartScreen displays a warning.
